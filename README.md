ИУ5-13Б Сикоринский Артемий Казимирович Вариант 3
Техническое задание проекта
Функции: 
	o Возможность работать с длинными арифметическими выражениями. 
	o Возможность работать с большими числами. 
 	o Функция ввода, вывода. 
	o Выполнение простейших арифметических операций (+, -, *, /). 
	o Выполнение таких операций, как: модуль, возведение в степень. 
	o Вычисление выражений со скобками. 
	o Проверка на корректность вводимых данных. 
 Системы: 
	o Система ввода. 
	o Система распознавания введённых символов (парсинг). 
	o Система проверки корректности вводимых данных. 
	o Система преобразования арифметического выражения в запись с однозначной последовательностью операций.
