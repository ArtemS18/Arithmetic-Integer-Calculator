# ПРАКТИКА ИУ5 1 КУРС
## ИУ5-13Б, Вариант – 13, Рубинштейн Илья. «Перцептрон».
### Краткая обрисовка:
Перцептрон – это простая нейросеть. Обучается на основе того, что ему показывают и предсказывает результат.
## ***Описание работы перцептрона:***
### Исходные данные:
Перцептрон получает на вход txt файл с цифрой, которая нарисована в удобном для нейросети режиме чтения. Поле файла txt заполнено нулями, а среди этих нулей цифра нарисована значениями (0,1].
### Инициализация «стоимости», принятие решений:
Стоимость необходима для принятия решений нейросети и её обучения.
В начале устанавливается рандомно.
Используя стоимость перцептрон, понимает, что пользователь загадал эту цифру. 
### Обучение нейросети:
Во время обучения перцептрон будет допускать ошибки (неверно сопоставлять элементы цифры). Чем больше попыток сделает перцептрон, тем больше будет вероятность правильно отгаданной цифры.
### Вывод результатов и статистики:
Пользователю будет представлено (вывод в консоль):
- вывод вероятности отгаданной цифры.
- вывод статистики – промежуточные результаты обучения(вероятности).
## ***Системы:***
### Система считывания входных данных:
Использование вектора для хранения «изображения» цифры.
Ячейки двумерного массива будут заполнены значениями в промежутке (0,1] (чем больше значение, тем лучше перцептрон понимает, к какой цифре оно относится).
### Система обработки входных данных:
Использование матрицы «стоимости», каждая строка которой описывает соединения между нейронами одного слоя с конкретным нейроном следующего слоя.
Использование вектора активации слоев (входных значений).
Произведение – умножение входного значения на соответствующую строку матрицы стоимости).
Использование вектора сдвига каждого произведения.
Сумма произведений с учетом сдвига образуют функцию активации, на основе которой перцептрон делает свой прогноз. 
### Система обучения:
- Создаем матрицу стоимости.
- Устанавливаем максимальное значение функции активации.
- Нейросеть делает свое предсказание.
- Оцениваем точность результата.
- Корректируем значения стоимости (с помощью градиентного спуска).
Алгоритм повторяется до тех пор, пока перцептрон не выдаст достаточно приближенный к истине результат.
### Система вывода/Сбора статистики:
- Считываем прошедшие через нейросеть входные данные из матрицы стоимости и функции активации (0,1).
- выводим полученную вероятность в консоль.
- Анализируем полученные данные/принимаем решение.
