# ИУ5-13Б Сикоринский Артемий Казимирович Вариант 3

## Техническое задание проекта

## ***Функции:***

 Возможность работать с длинными арифметическими выражениями. 
 Возможность работать с большими числами. 
 Функция ввода, вывода. 
 Выполнение простейших арифметических операций (+, -, *, /). 
 Выполнение таких операций, как: модуль, возведение в степень. 
 Вычисление выражений со скобками. 
 Проверка на корректность вводимых данных. 
 
## ***Системы:***
 Система ввода. 
 Система распознавания введённых символов (парсинг). 
 Система проверки корректности вводимых данных. 
 Система преобразования арифметического выражения в запись с однозначной последовательностью операций.
